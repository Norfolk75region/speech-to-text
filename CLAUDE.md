# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Утилита распознаёт речь из аудио- и видеофайлов через `faster-whisper` и сохраняет текст рядом с исходником в `<имя>_transcript.txt`. Её отдают людям, которые плохо разбираются в компьютерах. Поэтому все сообщения на русском, простыми словами, без трейсбеков и терминов. Git, тестов и линтеров нет.

## Запуск

- `install.bat` → `install.ps1` — установка для людей без Python. Скачивает uv (zip с GitHub releases) в `tools\uv\`, через него ставит Python 3.12 в `tools\python\` (`UV_PYTHON_INSTALL_DIR`) и создаёт `.venv`, затем `uv pip install -r requirements.txt` и проверка через `main.py --list-models`. В систему и PATH ничего не пишет. Скрипт можно запускать повторно; если `.venv` сломан (например, папку перенесли), окружение создаётся заново с `--clear`.
- `run.bat` — для пользователей. Его можно открыть двойным кликом (пошаговый режим) или перетащить на него файлы (аргументы уходят в `main.py`). Если `.venv` нет, сначала сам запускает `install.ps1`. В конце стоит `pause`.
- Файлы `.bat` держим в ASCII: кириллица в них ломается из-за кодовой страницы консоли. Весь русский текст живёт в `install.ps1`, а его нужно сохранять в **UTF-8 с BOM**, иначе Windows PowerShell 5.1 прочитает его как cp1251. Инструкция для пользователей — `ИНСТРУКЦИЯ.txt`.
- Пользователям отдаём папку без `.venv`, `tools`, `data` и `.idea`. `models/` можно приложить, чтобы им не пришлось скачивать модель.
- `.venv\Scripts\python main.py [файлы...] [-m модель] [-d auto|cuda|cpu] [-l ru|en|auto]`, `--list-models` — показать модели и рекомендацию.
- Проверка после правок: `.venv\Scripts\python -m py_compile main.py`, затем быстрый прогон с `--model tiny` на **копии** аудио из `data/` (иначе перезапишется транскрипт). При выводе в пайп задавай `PYTHONIOENCODING=utf-8`, иначе кириллица превращается в кракозябры.

## Как устроено (`main.py`)

- `detect_hardware()` ищет видеокарту через `ctranslate2.get_cuda_device_count()`, а название и объём видеопамяти берёт из `nvidia-smi`, если он есть. От этого зависит рекомендуемая модель: `large-v3-turbo` на видеокарте, `small` на процессоре или при видеопамяти меньше 3 ГБ.
- `MODELS` — список моделей для меню: имена совпадают с ключами `faster_whisper.utils._MODELS`. `pick_compute_type()` берёт самый экономный тип из поддерживаемых устройством.
- `Transcriber` загружает модель один раз на все файлы. При `RuntimeError` на видеокарте (не хватило памяти и т. п.) он переключается на процессор и распознаёт файл заново.
- Модели скачиваются в `models/` рядом со скриптом (`download_root`), а не в кэш HF. Так папку проекта можно целиком перенести на компьютер без интернета. `HF_HUB_VERBOSITY=error` выставляется до импорта, чтобы скрыть предупреждение HF про токен.
- Пошаговый режим (запуск без файлов) спрашивает путь (снимает кавычки и `& `, которые добавляет Windows при перетаскивании файла в окно), затем модель, и после каждого файла предлагает следующий. Модель спрашивается, только если `stdin` — терминал и `--model` не указан.

## Окружение

- Локальный `.venv` разработчика создан через uv на CPython 3.14, а `install.ps1` ставит пользователям 3.12. В `requirements.txt` версии закреплены: `av` 19 ломает faster-whisper 1.2.1 (`av.open()` больше не принимает `metadata_errors`). Обновлять версии только вместе с проверкой через чистую установку.
- Колесо `ctranslate2` для Windows уже содержит `cublas64_12.dll` и `cudnn64_9.dll`. Для работы на видеокарте нужен только драйвер NVIDIA, а пакеты `nvidia-*-cu12` в venv лишние.
