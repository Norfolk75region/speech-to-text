# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Утилита распознаёт речь из аудио- и видеофайлов через `faster-whisper` и определяет говорящих через `sherpa-onnx`. Рядом с исходником она пишет `<имя>_transcript.txt` (фразы с временем и «Спикер N»), `<имя>.srt`, а с `--words` ещё и `<имя>_words.json` со временем каждого слова. Её отдают людям, которые плохо разбираются в компьютерах. Поэтому все сообщения на русском, простыми словами, без трейсбеков и терминов. Тестов и линтеров нет; `models/`, `data/`, `.venv/` и `tools/` в git не попадают.

## Запуск

- `install.bat` → `install.ps1` — установка для людей без Python. Скачивает uv (zip с GitHub releases) в `tools\uv\`, через него ставит Python 3.12 в `tools\python\` (`UV_PYTHON_INSTALL_DIR`) и создаёт `.venv`, затем `uv pip install -r requirements.txt` и проверка через `main.py --list-models`. В систему и PATH ничего не пишет. Скрипт можно запускать повторно; если `.venv` сломан (например, папку перенесли), окружение создаётся заново с `--clear`.
- `run.bat` — для пользователей. Его можно открыть двойным кликом (пошаговый режим) или перетащить на него файлы (аргументы уходят в `main.py`). Если `.venv` нет, сначала сам запускает `install.ps1`. В конце стоит `pause`.
- Файлы `.bat` держим в ASCII: кириллица в них ломается из-за кодовой страницы консоли. Весь русский текст живёт в `install.ps1`, а его нужно сохранять в **UTF-8 с BOM**, иначе Windows PowerShell 5.1 прочитает его как cp1251. Инструкция для пользователей — `ИНСТРУКЦИЯ.txt`.
- Пользователям отдаём папку без `.venv`, `tools`, `data` и `.idea`. `settings.json` можно приложить, если хочется отдать уже настроенную программу. `models/` можно приложить, чтобы им не пришлось скачивать модель.
- `.venv\Scripts\python main.py [файлы...] [-m модель] [-d auto|cuda|cpu] [-l ru|en|auto] [-s N|auto] [-w] [-o папка] [--srt-only]`. `-s 1` отключает определение говорящих, `-o` кладёт результаты в другую папку (без него — рядом с записью), `--srt-only` не пишет `_transcript.txt`; в меню эти два флага не предлагаются, но из аргументов действуют и там. `--list-models` — показать модели и рекомендацию.
- Проверка после правок: `.venv\Scripts\python -m py_compile main.py diarization.py formats.py errors.py settings.py chunking.py`, затем быстрый прогон с `--model tiny -o <временная папка>`, чтобы не перезаписать результаты рядом с записью. При выводе в пайп задавай `PYTHONIOENCODING=utf-8`, иначе кириллица превращается в кракозябры.

## Как устроено

- `detect_hardware()` ищет видеокарту через `ctranslate2.get_cuda_device_count()`, а название и объём видеопамяти берёт из `nvidia-smi`, если он есть. От этого зависит рекомендуемая модель: `large-v3-turbo` на видеокарте, `small` на процессоре или при видеопамяти меньше 3 ГБ.
- `MODELS` — список моделей для меню: имена совпадают с ключами `faster_whisper.utils._MODELS`. `pick_compute_type()` берёт самый экономный тип из поддерживаемых устройством.
- `Transcriber` загружает модель один раз на все файлы. При `RuntimeError` на видеокарте (не хватило памяти и т. п.) он переключается на процессор и распознаёт файл заново.
- Модели скачиваются в `models/` рядом со скриптом (`download_root`), а не в кэш HF. Так папку проекта можно целиком перенести на компьютер без интернета. `HF_HUB_VERBOSITY=error` выставляется до импорта, чтобы скрыть предупреждение HF про токен.
- Меню (запуск без файлов, `main_menu()`): главный экран сразу ждёт файл — перетащили, ответили про говорящих, пошло распознавание с настройками по умолчанию. `1` — настройки (`settings_menu()`: модель, язык, «скачать всё для работы без интернета»), `2` — запуск с другими моделью, языком и `--words` на один раз, настройки при этом не меняются. `Session` держит `Transcriber` между запусками и пересоздаёт его, только если сменилась модель.
- Настройки по умолчанию (`settings.py`) лежат в `settings.json` рядом с программой, в git не попадают. JSON, а не TOML, потому что файл пишет само меню, а в стандартной библиотеке есть только чтение TOML. Порядок важности: аргумент командной строки → `settings.json` → рекомендация по железу (модель) или `ru` (язык). Испорченный файл молча заменяется значениями по умолчанию.
- Файлы: `split_dropped()` разбирает строку из окна (кавычки, `& ` от PowerShell, несколько путей через пробел), `expand_paths()` раскрывает папки — берёт аудио и видео по `MEDIA_EXTENSIONS`, без вложенных папок. То же работает для аргументов командной строки. Число говорящих спрашивается один раз на всю пачку.
- При перетаскивании на `run.bat` меню не показывается: берутся настройки по умолчанию, спрашивается только число говорящих (и только если `stdin` — терминал и нет `--speakers`).
- `is_model_downloaded()` проверяет наличие `model.bin` в снимке, а не папки модели: папка остаётся и после прерванной загрузки. `download_everything()` качает модель Whisper и все три модели диаризации (`Diarizer.download_all()`).
- Порядок в `Transcriber.transcribe()`: аудио декодируется один раз (`decode_audio`, 16 кГц), затем идёт диаризация на процессоре, затем Whisper получает тот же массив. `.txt` пишется по ходу распознавания, `.srt` и `.json` — в конце.
- Распознавание идёт **независимыми кусками**, а не подряд по записи. `chunking.plan_chunks()` находит речь через Silero VAD (он есть в faster-whisper) и собирает куски до 29 с, ставя границы в самых длинных паузах; тишина и музыка дольше 3 с в куски не попадают. Куски уходят в `BatchedInferencePipeline.transcribe(clip_timestamps=..., vad_filter=False)` с `initial_prompt` из `STYLE_PROMPTS` (образец пунктуации для `ru` и `en`; при `auto` язык сначала определяется по первому куску). Так выбрано по сверке с вычитанным эталоном на 10-минутной английской записи с музыкой. Обычный `model.transcribe` с `condition_on_previous_text=True` давал повторы фраз, «кашу» и разный результат от запуска к запуску; с `False` слова становились верными, но пунктуация пропадала окнами по 30 с, а `initial_prompt` там действует только на первое окно. Встроенная нарезка пакетного режима резала посреди предложения («soft / A bedient place»). Текущая схема: 1087 слов из 1087 при пяти ослышках, пунктуация везде, два прогона совпадают побайтно, 44 с вместо 4–5 минут. Менять параметры только с повторной сверкой на записи с эталоном.
- В пакетном режиме нет повторных попыток с другой температурой: если модель зациклится внутри одного куска, это останется в тексте. На тестах такого не было. `BATCH_SIZE` — 4 куска на видеокарте (large-v3 помещается в 4 ГБ), 2 на процессоре.
- `word_timestamps` включён всегда. `formats.build_phrases()` собирает из слов предложения (сегмент пакетного режима — это целый кусок), режет их там, где меняется говорящий (`SpeakerLookup` — двоичный поиск по отрезкам), а обрывки в одно-два слова на стыке голосов приклеивает к соседу. Без точек фраза режется по 30 с / 300 знаков.
- `formats.drop_invented()` убирает выдумки модели. Подписи авторов субтитров («Субтитры сделал…», «Редактор субтитров…») выбрасываются всегда; фразы, которые человек мог сказать сам («Спасибо за просмотр», «Продолжение следует», «Thank you for watching»), — только если это предложение целиком и оно стоит особняком (пауза от 1,5 с с обеих сторон) либо модель в нём не уверена. О выброшенном печатается строка «Убрана фраза…». На живой выдумке не проверено: с новой схемой они на тестовых записях не появились, проверка была только на искусственных примерах.
- `formats.build_cues()` собирает субтитры: реплика до 7 с и двух строк по 42 знака (с учётом «Спикер N: »), длинное предложение режется по запятым и паузам, короткие предложения подряд склеиваются в одну строку, реплики не накладываются, короткая держится секунду, если не мешает следующая.
- `diarization.py`: сегментация pyannote-segmentation-3.0 и **две модели голоса**. Если число людей известно, используется NeMo TitaNet-small (`num_clusters=N`), если нет — WeSpeaker ResNet34 с порогом `AUTO_THRESHOLD=0.7`, а говорящие, у которых меньше 5% речи, приклеиваются к соседу. Так выбрано по тестам: на монологе 21 мин, диалоге (живой голос + TTS) и записи с 4 говорящими из релизов sherpa-onnx. TitaNet в автоматическом режиме при любом пороге делил монолог на 2-3 человек, а WeSpeaker при известном числе путал 4 голоса. Порог менять только после повторной проверки на таких записях. Модели (7 + 40 + 26 МБ) скачиваются по мере надобности с GitHub releases `k2-fsa/sherpa-onnx` в `models/diarization/`.
- `errors.py`: `explain()` переводит исключение в объяснение для человека (нет места, мало памяти, нет интернета, нет доступа, файл пропал). Сетевые ошибки узнаются по именам классов во всей цепочке `__cause__`, чтобы не зависеть от того, чем качает huggingface_hub. `UserError` — текст уже готов для показа; так `Transcriber._read_audio()` сообщает про битый файл и видео без звука (декодер в этом случае бросает `IndexError`). Технический текст показывается только у незнакомых ошибок. Новый типовой сбой добавляй в `explain()`, а не печатай `{error}` на месте.
- Имена выходных файлов собираются через `with_name(stem + ...)`, а не `with_suffix`: в названиях записей бывают точки («Встреча 12.11.2026»).
- `hallucination_silence_threshold` против «Продолжение следует...» в обрыве записи не помог (тишина короче порога), а в пакетном режиме он не действует вовсе. Вместо него — `drop_invented()`.

## Окружение

- Локальный `.venv` разработчика создан через uv на CPython 3.14, а `install.ps1` ставит пользователям 3.12. В `requirements.txt` версии закреплены: `av` 19 ломает faster-whisper 1.2.1 (`av.open()` больше не принимает `metadata_errors`). Обновлять версии только вместе с проверкой через чистую установку.
- `sherpa-onnx` везёт свой onnxruntime и уживается в одном процессе с пакетом `onnxruntime` (на нём VAD faster-whisper); проверено чистой установкой.
- Колесо `ctranslate2` для Windows уже содержит `cublas64_12.dll` и `cudnn64_9.dll`. Для работы на видеокарте нужен только драйвер NVIDIA, а пакеты `nvidia-*-cu12` в venv лишние.
