# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Утилита распознаёт речь из аудио- и видеофайлов через `faster-whisper` и определяет говорящих через `sherpa-onnx`. Рядом с исходником она пишет `<имя>_transcript.txt` (фразы с временем и «Спикер N»), `<имя>.srt`, а с `--words` ещё и `<имя>_words.json` со временем каждого слова. Её отдают людям, которые плохо разбираются в компьютерах. Поэтому все сообщения на русском, простыми словами, без трейсбеков и терминов. Тестов и линтеров нет; `models/`, `data/`, `.venv/` и `tools/` в git не попадают.

## Запуск

- `install.bat` → `install.ps1` — установка для людей без Python. Скачивает uv (zip с GitHub releases) в `tools\uv\`, через него ставит Python 3.12 в `tools\python\` (`UV_PYTHON_INSTALL_DIR`) и создаёт `.venv`, затем `uv pip install -r requirements.txt` и проверка через `main.py --list-models`. В систему и PATH ничего не пишет. Скрипт можно запускать повторно; если `.venv` сломан (например, папку перенесли), окружение создаётся заново с `--clear`.
- `run.bat` — для пользователей. Его можно открыть двойным кликом (пошаговый режим) или перетащить на него файлы (аргументы уходят в `main.py`). Если `.venv` нет, сначала сам запускает `install.ps1`. В конце стоит `pause`.
- Файлы `.bat` держим в ASCII: кириллица в них ломается из-за кодовой страницы консоли. Весь русский текст живёт в `install.ps1`, а его нужно сохранять в **UTF-8 с BOM**, иначе Windows PowerShell 5.1 прочитает его как cp1251. Инструкция для пользователей — `ИНСТРУКЦИЯ.txt`.
- Пользователям отдаём папку без `.venv`, `tools`, `data` и `.idea`. `models/` можно приложить, чтобы им не пришлось скачивать модель.
- `.venv\Scripts\python main.py [файлы...] [-m модель] [-d auto|cuda|cpu] [-l ru|en|auto] [-s N|auto] [-w]`. `-s 1` отключает определение говорящих, `--list-models` — показать модели и рекомендацию.
- Проверка после правок: `.venv\Scripts\python -m py_compile main.py diarization.py formats.py errors.py`, затем быстрый прогон с `--model tiny` на **копии** аудио из `data/` (иначе перезапишется транскрипт). При выводе в пайп задавай `PYTHONIOENCODING=utf-8`, иначе кириллица превращается в кракозябры.

## Как устроено

- `detect_hardware()` ищет видеокарту через `ctranslate2.get_cuda_device_count()`, а название и объём видеопамяти берёт из `nvidia-smi`, если он есть. От этого зависит рекомендуемая модель: `large-v3-turbo` на видеокарте, `small` на процессоре или при видеопамяти меньше 3 ГБ.
- `MODELS` — список моделей для меню: имена совпадают с ключами `faster_whisper.utils._MODELS`. `pick_compute_type()` берёт самый экономный тип из поддерживаемых устройством.
- `Transcriber` загружает модель один раз на все файлы. При `RuntimeError` на видеокарте (не хватило памяти и т. п.) он переключается на процессор и распознаёт файл заново.
- Модели скачиваются в `models/` рядом со скриптом (`download_root`), а не в кэш HF. Так папку проекта можно целиком перенести на компьютер без интернета. `HF_HUB_VERBOSITY=error` выставляется до импорта, чтобы скрыть предупреждение HF про токен.
- Пошаговый режим (запуск без файлов) спрашивает путь (снимает кавычки и `& `, которые добавляет Windows при перетаскивании файла в окно), затем модель и число говорящих для каждого файла. После каждого файла предлагает следующий. Вопросы задаются, только если `stdin` — терминал и нет `--model` / `--speakers`. При перетаскивании файлов на `run.bat` число говорящих спрашивается один раз на все.
- Порядок в `Transcriber.transcribe()`: аудио декодируется один раз (`decode_audio`, 16 кГц), затем идёт диаризация на процессоре, затем Whisper получает тот же массив. При диаризации включается `word_timestamps`: `formats.build_phrases()` режет сегмент Whisper там, где по времени слов меняется говорящий (`SpeakerLookup` — двоичный поиск по отрезкам). `.txt` пишется по ходу распознавания, `.srt` и `.json` — в конце.
- `diarization.py`: сегментация pyannote-segmentation-3.0 и **две модели голоса**. Если число людей известно, используется NeMo TitaNet-small (`num_clusters=N`), если нет — WeSpeaker ResNet34 с порогом `AUTO_THRESHOLD=0.7`, а говорящие, у которых меньше 5% речи, приклеиваются к соседу. Так выбрано по тестам: на монологе 21 мин, диалоге (живой голос + TTS) и записи с 4 говорящими из релизов sherpa-onnx. TitaNet в автоматическом режиме при любом пороге делил монолог на 2-3 человек, а WeSpeaker при известном числе путал 4 голоса. Порог менять только после повторной проверки на таких записях. Модели (7 + 40 + 26 МБ) скачиваются по мере надобности с GitHub releases `k2-fsa/sherpa-onnx` в `models/diarization/`.
- `errors.py`: `explain()` переводит исключение в объяснение для человека (нет места, мало памяти, нет интернета, нет доступа, файл пропал). Сетевые ошибки узнаются по именам классов во всей цепочке `__cause__`, чтобы не зависеть от того, чем качает huggingface_hub. `UserError` — текст уже готов для показа; так `Transcriber._read_audio()` сообщает про битый файл и видео без звука (декодер в этом случае бросает `IndexError`). Технический текст показывается только у незнакомых ошибок. Новый типовой сбой добавляй в `explain()`, а не печатай `{error}` на месте.
- Имена выходных файлов собираются через `with_name(stem + ...)`, а не `with_suffix`: в названиях записей бывают точки («Встреча 12.11.2026»).
- Whisper иногда придумывает «Продолжение следует...» в обрыве записи. `hallucination_silence_threshold` против этого не помог (тишина короче порога), поэтому его не включали.

## Окружение

- Локальный `.venv` разработчика создан через uv на CPython 3.14, а `install.ps1` ставит пользователям 3.12. В `requirements.txt` версии закреплены: `av` 19 ломает faster-whisper 1.2.1 (`av.open()` больше не принимает `metadata_errors`). Обновлять версии только вместе с проверкой через чистую установку.
- `sherpa-onnx` везёт свой onnxruntime и уживается в одном процессе с пакетом `onnxruntime` (на нём VAD faster-whisper); проверено чистой установкой.
- Колесо `ctranslate2` для Windows уже содержит `cublas64_12.dll` и `cudnn64_9.dll`. Для работы на видеокарте нужен только драйвер NVIDIA, а пакеты `nvidia-*-cu12` в venv лишние.
