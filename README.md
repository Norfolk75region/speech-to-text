# Распознавание речи в текст

Программа для Windows: слушает аудио- или видеозапись и записывает сказанное в текстовый файл с временем каждой фразы и подписями, кто говорит. Работает на вашем компьютере, записи никуда не отправляются.

Рассчитана на людей, которые не разбираются в компьютерах: устанавливается двойным щелчком, Python ставить не нужно, все сообщения на русском.

## Что получается

Рядом с записью появляются файлы:

| Файл | Что в нём |
|---|---|
| `<имя>_transcript.txt` | Текст. У каждой фразы время, реплики подписаны «Спикер 1», «Спикер 2»... |
| `<имя>.srt` | Субтитры: короткие реплики до 7 секунд и двух строк. Если файл лежит рядом с видео, плеер покажет текст на экране |
| `<имя>_words.json` | Время каждого слова. Создаётся только по запросу |

Пример текста:

```text
Спикер 1
[00:00:00] Добрый день, начнём совещание.
[00:00:04] На повестке два вопроса.

Спикер 2
[00:00:09] Да, давайте с первого.
```

Номера идут по порядку: «Спикер 1» — тот, кто заговорил первым. Каждая строка текста — одно предложение.

## Установка

1. Скачайте архив: [speech-to-text-master.zip](https://github.com/Norfolk75region/speech-to-text/archive/refs/heads/master.zip).
2. Распакуйте его в удобное место, например в «Документы». После установки папку лучше не переносить; если перенесли, запустите `install.bat` ещё раз.
3. Дважды щёлкните `install.bat` и дождитесь надписи «Установка завершена». Нужен интернет, скачается около 150 МБ.

Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».

Установка ничего не меняет в системе: Python и все библиотеки складываются внутрь папки программы. Чтобы удалить программу, достаточно удалить папку.

## Как пользоваться

**Способ 1.** Перетащите запись мышкой на `run.bat`.

**Способ 2.** Дважды щёлкните `run.bat`, перетащите запись в чёрное окно и нажмите Enter.

Можно перетащить сразу несколько файлов или целую папку: записи распознаются по очереди. Из папки берутся только аудио и видео, вложенные папки не просматриваются.

Программа спросит, сколько человек говорит в записи:

- знаете число — введите его, так говорящие определятся точнее всего;
- говорит один человек — введите `1`;
- не знаете — нажмите Enter, программа определит сама, но может ошибиться.

В первый раз модель распознавания скачивается из интернета, это занимает несколько минут. Дальше интернет не нужен.

Подробная инструкция для пользователей лежит в файле `ИНСТРУКЦИЯ.txt`.

## Настройки

Дважды щёлкните `run.bat` и введите `1`. В настройках можно:

- **выбрать модель** — в списке видно, какие уже скачаны; выбранная запоминается;
- **выбрать язык записи** — русский, английский или «определять автоматически»;
- **скачать всё заранее**, чтобы потом работать без интернета.

Если другая модель или язык нужны только для одной записи, введите в главном окне `2` («запуск с другими параметрами»): настройки по умолчанию при этом не изменятся.

Настройки хранятся в файле `settings.json` в папке программы.

### Модели

| Модель | Размер | Когда выбирать |
|---|---|---|
| `tiny` | 75 МБ | очень быстро, но много ошибок |
| `base` | 145 МБ | быстро, качество посредственное |
| `small` | 490 МБ | хороший выбор для компьютера без видеокарты |
| `medium` | 1,5 ГБ | точнее, но без видеокарты медленно |
| `large-v3-turbo` | 1,6 ГБ | отлично и быстро на видеокарте |
| `large-v3` | 3 ГБ | максимальная точность, самая медленная |

Программа сама предлагает модель под компьютер: `large-v3-turbo`, если есть видеокарта NVIDIA с памятью от 3 ГБ, иначе `small`.

## Какие записи подходят

Практически любые аудио и видео: звук читается через встроенный FFmpeg. Из видео берётся только звуковая дорожка.

- Аудио: `.mp3` `.wav` `.m4a` `.aac` `.ogg` `.oga` `.opus` `.flac` `.wma` `.amr` `.aiff`
- Видео: `.mp4` `.mkv` `.mov` `.avi` `.webm` `.wmv` `.m4v` `.3gp` `.mpg` `.mpeg` `.ts` `.flv`

Этот список действует, когда вы перетаскиваете папку. Файл, указанный напрямую, программа попробует открыть с любым расширением.

## Что нужно компьютеру

- Windows 10 или 11.
- Интернет для установки и первого скачивания моделей.
- Видеокарта NVIDIA не обязательна, но с ней распознавание идёт в разы быстрее. Достаточно обычного драйвера, отдельно ставить CUDA не нужно.
- Свободное место: около 1,5 ГБ на программу плюс размер выбранной модели.

## Если что-то не так

- **Распознаёт очень долго.** Выберите в настройках модель поменьше (`small` или `base`). Без видеокарты NVIDIA это нормально.
- **Много ошибок в тексте.** Выберите модель побольше (`large-v3-turbo` или `large-v3`).
- **Реплики одного человека подписаны разными спикерами** или наоборот. Запустите ещё раз и введите точное число говорящих.
- **Текст пустой или обрывается в самом начале, хотя запись длинная.** В записи есть повреждённый кусок звука, и программа прочитала её только до него. Если установлен [FFmpeg](https://ffmpeg.org/), перегоните звук в WAV и распознайте его:

  ```bat
  ffmpeg -i "запись.avi" -vn -ac 1 -ar 16000 "запись.wav"
  ```

- **Программа показала ошибку.** Сделайте снимок экрана и пришлите тому, кто дал вам программу.

## Для тех, кто разбирается

Запуск из командной строки:

```bat
.venv\Scripts\python main.py [файлы и папки...] [-m модель] [-d auto|cuda|cpu] [-l ru|en|auto] [-s N|auto] [-w] [-o папка] [--srt-only]
```

| Параметр | Что делает |
|---|---|
| `-m`, `--model` | модель распознавания; по умолчанию из настроек или под компьютер |
| `-d`, `--device` | видеокарта (`cuda`), процессор (`cpu`) или `auto` |
| `-l`, `--language` | язык записи или `auto`; по умолчанию из настроек, изначально `ru` |
| `-s`, `--speakers` | число говорящих, `auto` — определить самому, `1` — не размечать |
| `-w`, `--words` | сохранить время каждого слова в `<имя>_words.json` |
| `-o`, `--output` | папка для результатов; без параметра они ложатся рядом с записью |
| `--srt-only` | писать только субтитры, без `<имя>_transcript.txt` |
| `--list-models` | показать модели, какие скачаны и какая рекомендуется |

Аргументы командной строки важнее сохранённых настроек.

Как устроено внутри:

- распознавание — [faster-whisper](https://github.com/SYSTRAN/faster-whisper). Запись режется на куски до 30 секунд по самым длинным паузам, и куски распознаются независимо: так на длинных записях не появляются повторы и не пропадает пунктуация;
- фразы в тексте и реплики субтитров собираются по времени каждого слова. Типовые фразы, которые модель дописывает на тишине и музыке («Продолжение следует...», «Thank you for watching»), убираются, и программа об этом сообщает;
- определение говорящих — [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx): сегментация pyannote-segmentation-3.0 и модели голоса NeMo TitaNet-small (число говорящих известно) или WeSpeaker ResNet34 (неизвестно);
- установка — [uv](https://github.com/astral-sh/uv) скачивает Python 3.12 и зависимости в папку программы;
- модели хранятся в папке `models/` рядом с программой, поэтому её можно целиком перенести на компьютер без интернета.

Подробности для разработки описаны в `CLAUDE.md`.
